# Changelog

## 0.1.1 — исправления
- Офлайн: при скачанном словаре отсутствующий файл (слово без примеров и т. п.) больше не уходит в сеть и не даёт «нет соединения».
- После скачивания, обновления или удаления словаря экраны перечитывают данные, а не показывают устаревшее из памяти сессии.
- История: записи разных лет с одинаковой датой («8 ноября») больше не роняют список из-за совпадающих ключей; у прошлых лет в подписи есть год.
- CI: публикация APK в GitHub Release получила права `contents: write` (раньше шаг падал с 403).
- Сборщик данных: `--out` больше не удаляет произвольный непустой каталог (только прежнюю сборку или пустой).
- Иконки: маска логотипа теперь создаётся в `assets/` и копируется в ресурсы `sync_icons.py`; исправлены устаревшие подсказки в скриптах и комментариях.

## 0.1.0 — итальянская версия
- Форк `datalaw_lexa` для итальянского: итальянско-русский словарь, `applicationId` `app.datalaw.lexa.it`.
- Сборщик данных переписан под русский Викисловарь (kaikki `ru-extract`), Tatoeba ITA↔RUS, wordfreq `it`; формы слов (`forms`, `form_of`, эвристика по толкованию), сопоставление форм с леммой в примерах (спряжение и род/число).
- Поиск без учёта диакритики (`perche` → `perché`).
- Убраны английские особенности: акценты US/UK, приставка «to».
- Подписи: одна строка для вкладок, кнопок, чипов и строк настроек; ровные переносы в абзацах; неразрывные пробелы после коротких слов, чисел и перед тире.
