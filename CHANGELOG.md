# Changelog

## 0.1.0 — итальянская версия
- Форк `datalaw_lexa` для итальянского: итальянско-русский словарь, `applicationId` `app.datalaw.lexa.it`.
- Сборщик данных переписан под русский Викисловарь (kaikki `ru-extract`), Tatoeba ITA↔RUS, wordfreq `it`; формы слов (`forms`, `form_of`, эвристика по толкованию), сопоставление форм с леммой в примерах (спряжение и род/число).
- Поиск без учёта диакритики (`perche` → `perché`); в карточках понимаются артикли.
- Убраны английские особенности: акценты US/UK, приставка «to».
- Подписи: одна строка для вкладок, кнопок, чипов и строк настроек; ровные переносы в абзацах; неразрывные пробелы после коротких слов, чисел и перед тире.
