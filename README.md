# datalaw_lexa_it — итальянско-русский словарь для Android (Kotlin)

Та же программа, что `datalaw_lexa`, но для итальянского: **Kotlin · Jetpack Compose · Material 3**. Ставится **рядом** с англо-русской версией (другой `applicationId` — `app.datalaw.lexa.it`, название «Lexa IT»).

Словарь работает онлайн (файлы читаются «на лету» и кэшируются), а после загрузки в настройках — полностью офлайн.

## Что отличается от англо-русской версии

- **Данные.** Источник — *русский* Викисловарь (через kaikki.org, `ru-extract`): в нём итальянские слова описаны по-русски, поэтому «Значения» — это русские толкования, а «Перевод» — короткие переводы, выделенные из толкований (по значениям, с пояснениями вроде «о погоде»). Предложения — Tatoeba ITA↔RUS, частотность — wordfreq (`it`).
- **Поиск.** Работает в обе стороны (итальянский ⇄ русский). Ударения можно не набирать: `perche` находит `perché`, `caffe` → `caffè`.
- **Формы слов.** `mangio`, `mangiato`, `case` ведут на лемму (`mangiare`, `casa`): из статей-форм Викисловаря и поля `forms`. Примеры из Tatoeba подбираются по основе слова и типичным окончаниям спряжения.
- **Без английских особенностей.** Приставка «to» перед глаголом убрана.
- **Озвучка и голосовой ввод** — `it-IT` / `ru-RU`. Выбор английского акцента убран (у итальянского он один).
- **Подписи.** Все короткие подписи (вкладки, кнопки, чипы, строки настроек) — в одну строку, без переносов; длинный текст переносится ровно (`LineBreak.Paragraph/Heading`, без переносов внутри слов), а короткие слова, числа и тире не отрываются от соседей (неразрывные пробелы в `ui/i18n/I18n.kt → typo()`).

## Сборка

JDK 17, Android SDK (compileSdk 35), Gradle 8.11+.

```bash
gradle wrapper --gradle-version 8.11.1      # один раз: создаёт ./gradlew
./gradlew :app:testDebugUnitTest            # юнит-тесты (Kotlin)
python3 scripts/test_build_data.py          # тесты сборщика данных (Python)
./gradlew :app:assembleDebug                # app/build/outputs/apk/debug/
```

Адрес словаря — `DATA_URL`; по умолчанию `https://raw.githubusercontent.com/diman-dragon/datalaw_lexa_it/dictionary/`. В CI он берётся из имени репозитория, ветка `dictionary` публикуется workflow'ом (репозиторий должен быть **публичным**).

## Данные

```bash
python3 scripts/build_data.py --sample                          # образец из нескольких слов
python3 scripts/build_data.py --download --require-wordfreq     # полная сборка (качает ~2 ГБ)
```

| Что | Источник | Лицензия |
| --- | --- | --- |
| Толкования, IPA, примеры, связи слов, формы, этимология | Русский Викисловарь через [kaikki.org](https://kaikki.org) | CC BY-SA |
| Частотность, отбор слов | [wordfreq](https://pypi.org/project/wordfreq/) | CC BY-SA |
| Предложения IT↔RU | [Tatoeba](https://tatoeba.org) | CC BY 2.0 FR |

**Важно.** Разбор рассчитан на схему wiktextract для русской редакции (`senses[].glosses`, `examples[].text/translation`, `forms`, `form_of`, `raw_tags`). Пока он проверен только на образце в `scripts/sample/`; на первой полной сборке посмотрите счётчики в логе (`статей принято`, `форм из поля forms добавлено`) и пару статей.

Переводы — не машинные: короткие фрагменты толкований Викисловаря. Если толкование описательное (длиннее 4 слов), перевода у значения не будет, но само толкование видно во вкладке «Значения».
